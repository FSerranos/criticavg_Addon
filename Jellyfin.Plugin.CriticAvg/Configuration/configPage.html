Critic AVG

Dozens of critics. One clear score. This plugin shows each film's Critic AVG score on its page and lets you sort your library by it.

The address of your Critic AVG site, the same one you open in the browser.
The same presets as the Critic AVG app.

On the film page (En la ficha)

Beside: ★ 6.8 · 🍅 100 · Critic AVG 7.4. The star and the tomato keep the film's own values.
Alone: only Critic AVG 7.4.
Works in Jellyfin web and the apps built on it (Android phone app, Jellyfin Media Player). TV apps (Android TV, Swiftfin, Roku…) don't run plugin scripts: they show whatever is in the field below. After saving, reload the page (F5).

Sorting (Ordenar)

Jellyfin can only sort by its own fields, so the Critic AVG score is stored in the one you pick here. Then in your library: Sort by → "Critics Rating" (or "Community Rating"). On the film page the plugin still shows that field's own value (Beside mode). Changing this gives the fields you stop using their own value back on the next run.
Scores change slowly; 7 days is plenty.
Keeps your server within OMDb's free 1,000 requests a day. A large library is covered over a few nights.

The scores update every night at 04:00. To run it now: Dashboard → Scheduled Tasks → Critic AVG → Update Critic AVG scores → ▶.
