Critic AVG

Dozens of critics. One clear score. This plugin writes each film's Critic AVG score into its rating, so you can sort and filter your library by it.

The address of your Critic AVG site, the same one you open in the browser.
The same presets as the Critic AVG app.
Sort by "Community rating" or "Critics rating" in your library to see films by Critic AVG.
Scores change slowly; 7 days is plenty.
Keeps your server within OMDb's free 1,000 requests a day. A large library is covered over a few nights.

The scores update every night at 04:00. To run it now: Dashboard → Scheduled Tasks → Critic AVG → Update Critic AVG scores → ▶.
